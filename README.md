# ShowMeYourTDs — live site

The published site for a 12-team Sleeper fantasy football league: playoff and
title odds, start/sit, matchup replays, daily puzzles and a play-calling game.

**Live:** https://ankithmareddy.github.io/fantasy-football-hub/

## This repo is a build artifact

Nothing here is written by hand. Every file is generated by `build_site.py`,
`build_arcade.py`, `dailygames.py` and `build_game.py` in the source repo, and
overwritten by its `deploy_site.sh` on each refresh — twice a day, on a clock.
The commit history is machine-generated and the diffs are data, not changes.

**Source, and the story of how it was built:
[AnkithMareddy/fantasy-football](https://github.com/AnkithMareddy/fantasy-football)**

If you want to understand the project, read that repo. If you want to look at
the numbers, open the live link.

## What gets published here

| File | Page |
|---|---|
| `index.html` + `data.json` | Dashboard — odds from a 10,000-season Monte Carlo, standings, matchups, waivers/FAAB, play-by-play team tendencies, weekly awards, highlights |
| `arcade.html` + `arcade.json` | Replay (scrub a matchup with a live win% curve), The Drill, Comeback |
| `daily.html` + `puzzles.json` | Daily puzzles, in an NFL-knowledge track and a league-knowledge track |
| `gridiron.html` + `teams.json` | Gridiron — an original play-calling game using each manager's real squad |
| `nav.js` | Shared navigation |

## A note on what is here

The odds, scores and team names are the same information the league's own
Sleeper page shows its members. No phone numbers, rosters beyond what the page
displays, or model code are published here — those stay in the source repo or
local to the machine that runs it.
