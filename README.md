# Fantasy Football Analytics Hub: live dashboard

The public dashboard for my 12-team fantasy football league, rebuilt automatically after every slate and refreshed nightly.

**Live:** https://ankithmareddy.github.io/fantasy-football-hub/

Shows playoff, bye, and title odds from a 10,000-run Monte Carlo season simulation, this week's matchups, waiver and FAAB activity, NFL team tendencies from play-by-play data, weekly awards, and highlights.

This repo holds only the built page (`index.html` + `data.json`). The pipeline that produces it is in [fantasy-football-analytics](https://github.com/AnkithMareddy/fantasy-football-analytics).
